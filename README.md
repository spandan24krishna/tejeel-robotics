# Tejeel Robotics Academy

Open `index.html` in Chrome, Edge or Firefox. No installation, build step, backend or API keys required. All included images and diagrams work offline; reference links require internet. Progress and dark mode are stored locally in each browser.

## Deployment
Upload `index.html`, `style.css`, `app.js` and the `assets` directory to a GitHub repository. Import it in Vercel, select **Other** as framework, leave build command blank and deploy the repository root. You can also use any static web host.

`content.md` is the editable curriculum source; `build.py` is optional and requires Python, mistune and beautifulsoup4. The included site is already built. The simulations are idealized teaching models, not hardware emulators. Code examples require board-specific wiring and validation. Images are extracted from the supplied course PDF; technical diagrams are original.
